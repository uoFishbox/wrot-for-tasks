# 未完了タスク

タスクをクリック・タップすると、同じWrotビューでその投稿の日付へ移動し、投稿を表示します。タスク行にフォーカスしてEnter・Spaceを押しても移動できます。通常表示・連続スクロール表示のどちらでも利用でき、非表示ルールの対象の投稿も表示します。投稿外に直接書かれたタスクは、元ノートの該当行を開きます。

未完了タスクエリアは、一覧を表示する通常モードと、`未完了タスク: タスク1, タスク2, …` のように簡易表示する最小化モードを切り替えられます。タスク名だけに `var(--text-muted)` を使い、見出しは通常の文字色を保ちます。簡易表示は1行に収め、幅に収まらない部分を省略記号で表示します。

PCの右サイドバーでは、最小化中も見出しの下に `var(--size-4-8)` の余白を確保します。

- 見出しまたは上端の境界線を下へドラッグすると最小化し、上へドラッグすると通常表示に戻ります。24px動かすとスナップし、小さな動きでは切り替わりません。
- 見出しのクリック・タップでも切り替えられます。
- 見出しにフォーカスした状態で、Enter・Spaceで切り替え、↓で最小化、↑で通常表示に戻せます。
- ドラッグ中にEscapeを押すとキャンセルします。ウィンドウがフォーカスを失った場合やポインター操作が中断された場合も、操作前の表示に戻ります。

最小化中もタスク名の簡易表示は更新されます。表示状態はObsidianのワークスペースにビューごとに保存されます。スナップのアニメーションは、OSの「視差効果を減らす」設定に従います。
