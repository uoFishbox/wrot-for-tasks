# 未完了タスクの使い方

未完了タスクエリアには、まだ完了していないタスクが表示されます。タスクをクリック・タップすると、同じWrotビューでその投稿の日付へ移動し、投稿を表示します。タスク行にフォーカスしてEnter・Spaceを押しても移動できます。通常表示・連続スクロール表示のどちらでも利用でき、非表示ルールの対象の投稿も表示します。投稿の外に書かれたタスクは、元のノートの該当行を開きます。

## 一覧をたたむ

タスク一覧を表示する通常モードと、`未完了タスク: タスク1, タスク2, …` のようにタスク名だけを1行にまとめた最小化モードを切り替えられます。最小化中もサマリーは最新の内容に更新されます。

- 見出しを下へドラッグすると最小化し、上へドラッグすると元に戻ります。
- 見出しをクリック・タップしても切り替えられます。

切り替えた状態はビューごとに保存され、次に開いたときも同じ表示で始まります。
