# Remaining tasks

The remaining-tasks panel shows tasks that are not yet done. Click or tap a task to navigate to its post's date and reveal the post in the same Wrot view. Enter or Space on a focused task row does the same. This works in both daily and continuous scrolling modes, including posts hidden by a tag rule. Tasks written outside a Wrot post open the corresponding line in the source note.

## Collapse the list

The panel can show the full task list or a minimized one-line summary such as `Remaining tasks: Task 1, Task 2, …`. The summary keeps updating while minimized.

- Drag the header down to minimize, or up to restore. 
- Click or tap the header to toggle modes.

Each view remembers its mode, so it opens in the same state next time.
